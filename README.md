# amazon-q-simple-rpg

- このゲームはAmazon Q CLI でゲームを作ろうTシャツキャンペーンで作成したコードです。
  - [Build Games with Amazon Q CLI and score a T shirt](https://community.aws/content/2xIoduO0xhkhUApQpVUIqBFGmAc/build-games-with-amazon-q-cli-and-score-a-t-shirt)
  - [日本語ページ](https://aws.amazon.com/jp/blogs/news/build-games-with-amazon-q-cli-and-score-a-t-shirt/)
- Amazon Q CLI のみで構築した某 RPG 風のゲームです。

## ゲーム概要

プレイヤーはキャラクターを操作し、敵とバトルをすることでレベルアップしていきます。

## 実行方法

1. リポジトリのクローンをします。
2. パッケージをインストールします。

   ```sh
   pip install pygame
   ```

3. ゲームを起動します。

   ```sh
   cd amazon-q-simple-rpg
   python3 simple_rpg.py
   ```
